# Backend

هذا المجلد مخصص للخدمات الخلفية للمنصة التعليمية.

## المقترح التقني
- Node.js
- TypeScript
- NestJS
- PostgreSQL
- Prisma
- Redis
- JWT

## الوحدات المقترحة
- auth
- users
- courses
- lessons
- enrollments
- assessments
- payments
- notifications
- admin
- reports

##بدء المشروع
- npm install
- npm run dev

## القواعد
- التحقق من المدخلات
- التعامل الآمن مع JWT
- كتابة اختبارات لوحدات الخدمة الأساسية
- استخدام Prisma للطبقة المادية
