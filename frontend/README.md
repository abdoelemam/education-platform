# Frontend

هذا المجلد مخصص للواجهة الأمامية للمنصة التعليمية.

## المقترح التقني
- React
- Next.js
- TypeScript
- Tailwind CSS
- React Query
- Zustand

## الصفحات المقترحة
- الصفحة الرئيسية
- تسجيل الدخول والتسجيل
- الدورات
- تفاصيل الدورة
- لوحة الطالب
- لوحة المعلم
- لوحة الإدارة
- باقات الاشتراك

## البدء
- npm install
- npm run dev

## القواعد
- تصميم متجاوب وموبايل أولاً
- استخدام مكونات قابلة لإعادة الاستخدام
- تنظيم الحالة بشكل واضح
- كتابة اختبارات للصفحات الأساسية عند الحاجة
